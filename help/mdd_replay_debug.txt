--------------
1. Information
--------------
Console output about replay sync points.

Console output about replay sync points: when the teleport was seen, which serverTime recorded cmd 0 maps to, how many ms were skipped, grid vs time-based matching.

Default: "0"   Added: 2026-10-21

-----------------
2. Usage examples
-----------------
mdd_replay_debug 1
    Check why a playback started late or drifted.
