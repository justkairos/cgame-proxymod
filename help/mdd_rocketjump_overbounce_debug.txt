--------------
1. Information
--------------
Console checks, RESULT line and rjob.log for every use.

+mdd_rocketjump_overbounce: 1 prints the chosen candidate, the checks against the server and a RESULT line for every use, and appends the full detail to rjob.log in the mod folder: the starting state and cvars, every usercmd sent (time, pmove slot, keys, view), the frames around the jump, and every server playerstate of the whole flight next to the predicted one.

Default: "0"   Added: 2026-11-10

--------
2. Notes
--------
Part of +mdd_rocketjump_overbounce; see that entry for the whole feature.

-----------------
3. Usage examples
-----------------
mdd_rocketjump_overbounce_debug 1
    Turn it on, use the key a few times, read the RESULT lines.

mdd_rocketjump_overbounce_debug 0
    Off again: no console output, no log file.
