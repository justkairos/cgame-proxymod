============================
BUTTON: +mdd_overbounce_zero
============================

1. Information
2. Notes
3. Usage examples
4. See also

-------------------------------
bind <key> +mdd_overbounce_zero
-------------------------------

--------------
1. Information
--------------
Brings your horizontal velocity to exactly 0 in the air, for a vertical overbounce.

While held in the air: uses the movement keys to bring your horizontal velocity to EXACTLY 0 so the landing is a vertical overbounce. A vertical overbounce needs horizontal speed below 1 at the overbounce frame. Velocities are snapped to integers, so the last step is done walking (1.29 ups per frame: 1 -> 0) instead of running (2.56: 1 -> -2 -> 1 forever). On CPM it also ducks for the last few units.

Works best on VQ3. On CPM the side-strafe air acceleration can't settle near zero, so it only uses forward / back close in and may leave a sideways unit if you aren't looking roughly along your velocity.

Added: 2026-10-20

--------
2. Notes
--------
This is a hold button like +forward or +attack: bind it to a key and it is active while the key is held. Several can share one key, e.g. bind shift "+mdd_grenade_chase;+mdd_grenade_aim".

Everything the proxymod does goes through the engine's own buttons (+forward, +moveup, +attack, +left, ...), so the server sees ordinary input and your physical keys keep working. Automated jump and attack presses are held a random mdd_input_stagger_min..max ms, a jump + attack pair is never sent in the same usercmd, and no timing pattern repeats within 256 pairs.

-----------------
3. Usage examples
-----------------
bind mouse5 +mdd_overbounce_zero
    Fall from an overbounce height holding mouse5 to bounce straight back up.

bind mouse5 "+mdd_overbounce_zero"
    After a straight-down +mdd_rocketjump_overbounce, hold it during the fall to keep the bounce vertical.
