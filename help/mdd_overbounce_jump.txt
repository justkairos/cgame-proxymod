============================
BUTTON: +mdd_overbounce_jump
============================

1. Information
2. How it decides
3. Notes
4. Usage examples
5. See also

-------------------------------
bind <key> +mdd_overbounce_jump
-------------------------------

--------------
1. Information
--------------
Jumps on the first usercmd after an overbounce landing gave you its speed.

While held: if you land with an overbounce, jumps in the usercmd right after the one that converted your fall speed into overbounce speed. Jumping any earlier would cancel the overbounce, so this is the earliest possible overbounce jump.

Added: 2026-10-20

-----------------
2. How it decides
-----------------
An overbounce landing is detected from the predicted player state: grounded while the z velocity is still large negative and still decreasing (a normal or slope landing always raises it). The next time the velocity changes the overbounce has happened; if you are still on the floor it taps jump. On tall overbounces the leftover upward velocity briefly flags you as jumping away; it waits up to 150 ms for the ground flag to return. Only horizontal (go) overbounces get a jump; a vertical one launches you anyway. mdd_overbounce_debug 1 prints what it saw.

--------
3. Notes
--------
This is a hold button like +forward or +attack: bind it to a key and it is active while the key is held. Several can share one key, e.g. bind shift "+mdd_grenade_chase;+mdd_grenade_aim".

Everything the proxymod does goes through the engine's own buttons (+forward, +moveup, +attack, +left, ...), so the server sees ordinary input and your physical keys keep working. Automated jump and attack presses are held a random mdd_input_stagger_min..max ms, a jump + attack pair is never sent in the same usercmd, and no timing pattern repeats within 256 pairs.

-----------------
4. Usage examples
-----------------
bind space +mdd_overbounce_jump
    Walk off a ledge at an overbounce height holding space: you jump with the full speed.

bind space "+mdd_overbounce_jump;+mdd_autojump"
    Overbounce jump when there is one, a normal landing jump otherwise.

mdd_overbounce_debug 1
    See whether a landing was recognised as an overbounce.
