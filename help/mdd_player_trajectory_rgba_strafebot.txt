1. Information
--------------
Colour of the strafebot model's samples.

Colour and opacity of the strafebot model's samples, each 0..1. Default 0 .5 0 .5.

Default: "0 .5 0 .5"   Added: 2026-10-27 (written 2026-08-28 by akuzmichov)

2. Notes
--------
Part of the predicted player trajectory by akuzmichov (merged from github.com/akuzmichov/cgame-proxymod, branch player_trajectory). The full reference is docs/mdd_player_trajectory.md in the repository.
