--------------
1. Information
--------------
Colour of the accel model's samples.

Colour and strength of the accel model's samples, each 0..1. Default .4 .4 0 1.

The fourth value (alpha) is how strong it is drawn: 1 full, lower fainter, 0 invisible. The stock shaders are additive and ignore alpha by themselves, so the colour is multiplied by it before drawing; .5 .5 .5 1 and 1 1 1 .5 look the same.

Default: ".4 .4 0 1"   Added: 2026-10-27 (written 2026-08-28 by akuzmichov)

--------
2. Notes
--------
Part of the predicted player trajectory by akuzmichov (merged from github.com/akuzmichov/cgame-proxymod, branch player_trajectory). The full reference is docs/mdd_player_trajectory.md in the repository.

-----------------
3. Usage examples
-----------------
mdd_player_trajectory_rgba_accel .4 .4 0 1
    Default.

mdd_player_trajectory_rgba_accel 1 1 1 .3
    Faint white.

mdd_player_trajectory_rgba_accel .4 .4 0 .25
    The default colour at a quarter strength.
