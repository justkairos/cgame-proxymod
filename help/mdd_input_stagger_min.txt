mdd_input_stagger_min <ms>

--------------
1. Information
--------------
Lower end of the randomizer behind every automated jump and shot.

mdd_input_stagger_min..mdd_input_stagger_max is the one randomizer behind every automated jump and shot (+mdd_jumpshoot, +mdd_rocketsync, +mdd_rocketstack, mdd_grenade_jump / shoot / sync, +mdd_overbounce_jump, pad shots). Defaults 8 and 64.

Values are whole usercmds: the range is rounded up to usercmd counts (8..64 = 1..8 usercmds at 125 fps) and every count is equally likely. Every automated key press is held for a random value from this range. When jump and attack are pressed as a pair (within 150 ms of each other), the second one is released a random value from this range AFTER the first one's release, and the press gap of +mdd_jumpshoot is drawn from it too. Two automated key events are never put in the same usercmd.

The (press gap, first hold, release gap) pattern of every pair is compared with the last 256 patterns and re-rolled, so no two jump + shots in a demo look alike.

Default: "8"   Added: 2026-10-23

--------
2. Notes
--------
Replaces the old mdd_input_time / mdd_input_time_randomize. mdd_input_debug 1 prints the real usercmd times of every pair.

-----------------
3. Usage examples
-----------------
mdd_input_stagger_min 8; mdd_input_stagger_max 64
    Defaults.

mdd_input_stagger_min 8; mdd_input_stagger_max 16
    Tight: everything within one or two usercmds.

mdd_input_debug 1
    Print what was really sent.
