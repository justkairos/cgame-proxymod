--------------
1. Information
--------------
Colour of jump frames of any model.

Colour and opacity of jump frames of any model, each 0..1. Default .8 0 0 .8.

Default: ".8 0 0 .8"   Added: 2026-10-27 (written 2026-08-28 by akuzmichov)

--------
2. Notes
--------
Part of the predicted player trajectory by akuzmichov (merged from github.com/akuzmichov/cgame-proxymod, branch player_trajectory). The full reference is docs/mdd_player_trajectory.md in the repository.

-----------------
3. Usage examples
-----------------
mdd_player_trajectory_rgba_jump .8 0 0 .8
    Default.

mdd_player_trajectory_rgba_jump 1 1 1 .3
    Faint white.
