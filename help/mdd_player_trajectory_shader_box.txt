--------------
1. Information
--------------
Shader used for the boxes and footprints.

Shader NAME (not an image path) for every drawn box and footprint. Takes effect immediately. A custom look needs a .shader script in a pk3 that defines the name.

Default: "bbox_nocull"   Added: 2026-10-27 (written 2026-08-28 by akuzmichov)

--------
2. Notes
--------
Part of the predicted player trajectory by akuzmichov (merged from github.com/akuzmichov/cgame-proxymod, branch player_trajectory). The full reference is docs/mdd_player_trajectory.md in the repository.
