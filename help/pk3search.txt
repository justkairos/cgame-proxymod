==================

1. Information

-----------------------------------
pk3search <pattern> [<pattern> ...]
-----------------------------------

--------------
1. Information
--------------
Finds files and folders by name in every pk3, and says which pk3 each is in.

Searches the names of all files and all folders in every pk3 of the mod folder and the base game folder. Two lists are printed: files first, then folders. Each line is the pk3 followed by the path inside it. pk3files prints only the file list, pk3folders only the folder list.

Added: 2026-11-25

-----------
2. Patterns
-----------
* is any run of characters, ? exactly one character, [a-z] one character out of a set; case does not matter.

Without a wildcard it is a "contains" search: pk3search rocket finds every name with rocket in it.

With a wildcard the whole name has to match, the name being the last part of the path, with or without its extension: rocket* is names that start with rocket, *rocket names that end with it (rocket.tga counts), *.arena every arena script, *rock*fire* anything with both in that order.

To match the whole path instead of the name, put a backslash in the pattern: pk3files maps\*run*. A forward slash works only inside quotes (pk3files "maps/*run*"): the console treats /* as the start of a comment and throws away the rest of the line before the command ever sees it.

Several patterns can be given; a name is listed if any of them matches.

--------
3. Notes
--------
The engine gives a cgame no way to list files, so this reads the disk itself: the mod folder is the folder the proxymod DLL was loaded from, the base game folder (baseq3) is next to it, and a pk3 is a zip file whose list of names sits at its end and is read without unpacking anything. Only pk3 archives are searched, not the loose files of those folders, and not other mod folders.

Nothing is cached: every search reads the archives again, so it always shows what is on disk. With over a thousand pk3s the first search after starting the PC takes a few seconds, later ones well under a second. At most 1000 lines are printed per list; the count at the end is always the full number.

-----------------
4. Usage examples
-----------------
pk3search rocket
    Every file and folder with "rocket" in its name, and the pk3 it is in.

pk3files *.arena
    All arena scripts.

pk3files *plasma*.bsp
    Maps with plasma in the name, with their pk3.

pk3files rocket*
    Files whose name starts with rocket.

pk3folders sky*
    Folders whose name starts with sky.

pk3files maps\*run*
    A whole-path pattern: everything under maps/ with run in it.

pk3search textures\*\lava*
    Whole path again: lava files and folders one level below textures/.
