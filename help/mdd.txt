--------------
1. Information
--------------
mDd client proxymod with Evan's automation additions. Install: put the cgame DLL into the defrag folder and set "seta vm_cgame 0". Type "mdd_" and press tab in the console to list everything.

Help on any of these: "mdd_help <name>" or defrag's "? <name>" (both read system/help/<name>.txt).

----------------
2. Grenade tools
----------------
mdd_grenade_chase, mdd_grenade_aim, mdd_grenade_jump, mdd_grenade_shoot (cvars 0/1 and +mdd_grenade_* hold buttons)
mdd_grenade_sync (cvar 0/1 and +mdd_grenade_sync), mdd_grenade_sync_offset
mdd_grenade_last, mdd_grenade_lead, mdd_grenade_jump_lead, mdd_grenade_debug

----------------------
3. Jump / rocket tools
----------------------
+mdd_jumpshoot, +mdd_rocketsync, +mdd_rocketstack
mdd_rocketsync_lead, mdd_rocketsync_jump_lead, mdd_rocketstack_offset, mdd_rocket_debug

-------------------
4. Overbounce tools
-------------------
+mdd_yaw, mdd_yaw_ywh, mdd_yaw_rgba (yaw marks, like mdd_pitch)
mdd_player_trajectory_* (predicted hitbox path, by akuzmichov)
+mdd_autojump (mdd_autojump_stagger_min/max, mdd_autojump_debug)
mdd_overbounce_jump, +mdd_overbounce_zero, mdd_overbounce_debug

6. Input timing
---------------
mdd_input_stagger_min, mdd_input_stagger_max, mdd_input_debug
